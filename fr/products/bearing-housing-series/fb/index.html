Application

Construction standard sur tous les modèles : boîtier palier à semelle en fonte grise HT200 avec trous de montage taraudés, cavité intérieure sphérique offrant une capacité d’autalignement de ±2° pour compenser le désalignement de l’arbre, finition peinte antirouille, conçu pour recevoir les roulements insérés de la série UC. Les trous taraudés suppriment les boulons traversants, ce qui est idéal pour le montage sur des panneaux de machines minces.
