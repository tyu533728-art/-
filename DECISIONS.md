# Decisions

## V4.0 Static Architecture

Generate independent localized HTML routes instead of runtime language switching or URL parameters. This keeps every language crawlable and avoids client-side application complexity.

## Data Publication Rule

Do not publish a product model, parameter table or Product Schema until the underlying technical values have an approved source. Reference imagery is not treated as technical data.

## Product Publication Policy

The public hierarchy is Pillow Block Bearing Units, Bearing Housing Series and Custom. Only active Series with confirmed images generate pages; pending Series remain in data only. No model pages, parameter tables or Product Schema are generated.

## Contact Policy

Contact details are public information in the Footer and Contact Us page only. The website never collects visitor data.
