Стандартная конструкция для всех моделей: высокий опорный корпус из серого чугуна HT200, сферическая внутренняя полость, обеспечивающая самоустановку ±2° для компенсации несоосности вала, антикоррозионное лакокрасочное покрытие, рассчитан на установку вставных подшипников серии UC. Приподнятое основание создаёт зазор под валом для ограждений и требований по пространству.
