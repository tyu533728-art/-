Стандартная конструкция для всех моделей: подвесной корпус из серого чугуна HT200 для монтажа в подвешенном положении, сферическая внутренняя полость, обеспечивающая самоустановку ±2° для компенсации несоосности вала, антикоррозионное лакокрасочное покрытие, рассчитан на установку вставных подшипников серии UC. Подвесная конструкция для подвесных конвейерных и элеваторных систем.
