Особенность
Скользящая конструкция натяжителя, перемещение по направляющим, самоустанавливающееся сферическое посадочное отверстие
Применение
Натяжение конвейерной ленты, натяжение цепей, сельскохозяйственная техника, оборудование для перемещения материалов

Стандартная конструкция для всех моделей: корпус из серого чугуна HT200 с направляющими пазами для осевой регулировки, сферическая внутренняя полость, обеспечивающая самоустановку ±2° для компенсации несоосности вала, антикоррозионное лакокрасочное покрытие, рассчитан на установку вставных подшипников серии UC. Идеально подходит для применений, требующих натяжения ремня или цепи и гибкого позиционирования вала.
